# Project 1: Car Foreground Detection and Driving Scenario Simulation

## Overview
This project simulates an autonomous driving scenario and vehicle trajectory monitoring using Python, Matplotlib, and OpenCV. It models an oval track road layout, generates waypoints for multiple vehicles moving at different speeds, and plots real-time dynamic trajectories.

---

## Aim
To model driving scenarios, simulate multi-vehicle trajectories, and visualize road boundaries and vehicle movements in real time.

---

## Objectives
- Construct an oval track road network with defined lane boundaries.
- Define initial positions, speeds, and trajectories for an Ego vehicle and a fast vehicle.
- Simulate and update vehicle movements in real-time using interactive plotting.
